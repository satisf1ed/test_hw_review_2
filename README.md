# Инженерия данных и LLM: воспроизводимая оценка

## Правила работы

- main содержит правила курса и доверенный манифест .reviewflow/course.json. Не отправляйте домашние задания в main.
- hw_1, hw_2, hw_3, hw_4 созданы как независимые корневые ветки заданий с условиями, критериями, эталонным кодом и доверенными тестами Python unittest. Решения разных заданий не объединяются последовательно.
- Отправляйте solutions/hw_N/<slug> в hw_N. Во время разбора не объединяйте и не закрывайте PR.
- Запускайте Python только в Docker без доступа к сети и с ограниченными ресурсами. Не устанавливайте зависимости и не запускайте вложения. Тесты служат свидетельством, а не оценкой.
- Оценки и подтверждения проверяющих оформляются отдельно. Манифест не содержит оценок.
