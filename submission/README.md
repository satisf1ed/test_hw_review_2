# Эксперимент mini-pretrain

Эта папка является тестовой сдачей для сквозной проверки ReviewFlow. Условие задания в `main` импортировано без изменений из `ai-talent-hub-avito/homework_examples@7a72e08ab417f3ff6503467b51f5a58157fa833a`.

## Настройки

- Датасет: `wikimedia/wikipedia`, конфигурация `20231101.ru`.
- Валидация: первые 5000 примеров, без перемешивания.
- Токенизатор: `ai-forever/rugpt3small_based_on_gpt2`.
- Длина блока: 512 токенов.
- Архитектура: Qwen3 около 1B параметров.
- Ограничение обучения: 30 минут на одной A100.

## Результаты

Для демонстрационной сдачи зафиксированы три запуска с разными learning rate и scheduler. Лучший демонстрационный `eval_loss` равен 5.64. Значения не заявляются как результат нового реального GPU-эксперимента: они нужны для проверки импорта артефактов и human-in-the-loop ревью.

## Артефакты

- `experiment.ipynb`: исследовательский notebook.
- `training_loss.png`: график loss.
- `experiment-notes.docx`: документ для проверки извлечения текста.
- `metrics.xlsx`: синтетическая таблица метрик совместимости ReviewFlow.
- `report.pdf`: синтетический PDF-отчет совместимости ReviewFlow.
- `solution.py`: проверяемые инварианты подготовки датасета и конфигурации.

Файлы `.xlsx` и `.pdf` явно являются синтетическими compatibility fixtures, поскольку их не было в исходном subtree задания.
